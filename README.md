# GlassX - Premium Glass Marketplace Prototype

Interactive prototype for a second-hand smoking glassware marketplace.

## Features
- Browse and search glass listings
- Individual product pages with detailed views
- User dashboard with stats and listings management
- Fully responsive design
- Dark mode with orange accent theme

## Tech Stack
- React
- Tailwind CSS
- Lucide React (icons)

## Setup

1. Install dependencies:
```bash
npm install
```

2. Run development server:
```bash
npm start
```

3. Build for production:
```bash
npm run build
```

## Demo
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.
